44: ## Method
45: 
46: - `make_prompts.py` builds the prompts from the repository's own text at v0.1.41 (docs and source files), so they can be
47:   shared and rebuilt; the file it writes has the sha256 given in the script. Every prompt is a different slice of that
48:   text and starts with its own run id, so no request can reuse another one's prefix (the engine reported 0 reused tokens
49:   for every run). The task line asks for a one-paragraph summary.
50: - `benchmark.py`: a fresh server; the model's page cache dropped before it started; startup is not timed. One
51:   ~1,000-token warm-up request (not counted), then three runs at each size, one request at a time, streamed. The expert
52:   cache stays warm across runs and its adaptive tier is on (the default).
53: - Prompt and decode throughput come from the server's `timings` (the engine's own clock; decode counts the reasoning
54:   tokens). TTFT is the client's time from sending the request to the first streamed token (reasoning text).
55: - Memory: MemAvailable and VRAM after each request, and a memory guard that samples MemAvailable, free VRAM, the server's
56:   process-tree RSS and swap every 0.2 s for the whole session.
57: - Then, on the same server: `python tools/needle_bench.py --url http://127.0.0.1:8081 --lengths 32k,128k --depths 10,50,90`.

87:   (`STRATA_DS4_SLOT_GB`) and are removed after a week. `STRATA_DS4_AUTO_PIN=1` also keeps the system prompt and tools shared by an agent

92: ## Tuning
93: 
94: `strata launch --tune quick` (or `thorough`, or the Tuning screen) works for DeepSeek with its own short tuner, `tools/dsv41/tune.py`. It starts
95: the engine a few times on a fixed short question and measures the answer speed: the standard settings first, then the DSpark drafter forced on,
96: then a shorter draft block (3), then one CPU thread for each physical core (thorough also tries every logical thread). A setting is kept only for a
97: gain of more than 5%, and the result is written into the launch's settings. Expect about 5 to 10 minutes (each run loads the model, which takes
98: 1 to 3 minutes); close other heavy programs first. If a run fails or the computer is too busy to tell, the standard settings stay and one plain line
99: says so. The RAM store (`--ssd-cache`) sizes itself when the model starts, so the tuner does not touch it, and the context stays what you chose.
